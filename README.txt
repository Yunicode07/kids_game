몽실이와 놀이터 - 앱으로 설치하는 방법

이 폴더를 https 웹 주소에 올리면 휴대폰, 태블릿, PC에 앱으로 설치할 수 있어요.
설치하면 홈 화면 아이콘으로 바로 열리고, 처음 한 번 연 뒤에는 인터넷 없이도 놀 수 있어요.

[무료로 올리는 방법 예시: Netlify Drop]
1. https://app.netlify.com/drop 에 접속해요.
2. 압축을 푼 이 폴더(index.html이 있는 폴더)를 화면에 끌어다 놓아요.
3. 만들어진 https 주소를 휴대폰이나 태블릿에서 열어요.

[GitHub Pages로 올리는 방법]
1. 새 저장소를 만들고 이 폴더의 파일을 모두 올려요.
2. Settings > Pages 에서 main 브랜치를 선택하고 저장해요.
3. 잠시 뒤 나오는 https 주소를 열어요.

[설치]
- 안드로이드, PC(Chrome, Edge): 화면 오른쪽 위 톱니 버튼을 3초 길게 누르고 "앱 설치" 메뉴에서 "앱으로 설치하기"를 눌러요.
  버튼이 안 보이면 브라우저 메뉴(⋮)에서 "앱 설치" 또는 "홈 화면에 추가"를 눌러요.
- 아이폰, 아이패드: Safari로 주소를 열고 공유 버튼 > "홈 화면에 추가"를 눌러요.

[그림이나 코드를 바꾼 뒤 다시 올릴 때]
sw.js 맨 위의 CACHE 이름(mongsil-v1)을 mongsil-v2처럼 바꿔야 이미 설치된 앱에도 새 내용이 반영돼요.

참고: 컴퓨터에서 index.html 파일을 그냥 더블클릭하면 놀 수는 있지만 앱 설치는 안 돼요(https 주소가 필요해요).
